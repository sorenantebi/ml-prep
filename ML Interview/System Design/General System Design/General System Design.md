# General System Design

Hello Interview–style system design question bank: 32 classic problems grouped by theme. Each problem has its own folder with:
- **Question**: prompt, requirements to clarify, scale hints and things to think about (no answers)
- **Solution**: requirements, estimates, API, high-level design, deep dives, trade-offs and pitfalls
- **Diagram**: Excalidraw high-level design (some also have a deep-dive diagram)

**How to use:** read the question, spend 35-45 minutes designing it yourself on a blank Excalidraw/doc, then compare with the solution. Tick the box when you could do it cold.
